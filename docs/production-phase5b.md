# Phase 5-B：無料処理の自動進行

ホームの「制作工程の自動進行」で、現在の対象・件数・保存先・依存順を表示する。確認チェック後に「次の自動処理を実行」または「実行可能な無料処理を進める」を押す。一括実行は最大32処理、プロンプトZIPは1処理24コマまで。依存条件を処理ごとに読み直し、承認が必要な工程や素材不足で停止する。

対象はプロンプト/参照PNG/対象確認票ZIP、変更ページPNG、全ページPDF/PNG ZIP、無料モック音声、字幕タイムライン、承認済み動画計画による3形式MP4、既存の完成素材検証。生成元の変更でプレビューの承認トークンを失効させる。実行中に脚本・人物・画像・ページ配置・保存済み動画計画が変わった場合は停止する。

企画・脚本の採用と確定、人物同定・設定・バイブル、基準画像/コマ画像の確認と採用、ページ構成の確認・保存、動画計画の編集と利用権の承認、音声の試聴、最終品質と権利・公開判断は人間の操作として残す。無料トーンやテスト画像は本番品質の完了にはならない。既存の有料音声設定があれば、無料設定に勝手に書き換えず音声自動処理を止める。有料API・外部送信・GitHub同期・SNS投稿は自動実行しない。

## 保存・再開・差分

進捗の正本は既存Store。自動処理履歴は既存StudioStoreの任意項目 `automation_jobs` に追加し、出力も既存の `exports` と不変ファイル保存を使う。生成元ごとのキー、実ファイルSHA、排他的な作品単位ロックで再利用・二重実行防止を行う。失敗した出力や古い履歴は削除しない。中断した自動ジョブは次の承認実行で再計画する。音声・画像・動画の保存途中状態は既存の復旧画面で解消してから再開する。

ページのキーはページ内容・配置・設定・対象コマの画像と指示・ファイル状態から計算する。別ページの候補追加等ではそのPNGを描画し直さない。書籍はページキーの集合から判定する。音声はVoiceServiceの発話キャッシュを再利用する。動画は形式ごとに既存VideoServiceの指紋を使うため、1形式の字幕表示設定変更で他形式の再出力を要求しない。

脚本版変更時の人物・画像・バイブルの鮮度判定はPhase 5-Aの保守的な仕様を維持する。元データを確認・再採用した後、実内容に変更のないページPNGは再利用できる。PDF/PNG ZIPは既存 `export_book` を再利用して書籍全体を生成するため、書籍内部の変更ページだけを置換する処理ではない。

プロンプトZIPを取得し、ChatGPT等で画像を作り、既存の手動画像制作で画像と確認票を取り込む。候補原本・変換後画像・確認票の整合はImageAIServiceが検証する。プログラムから一括取り込みする場合は `Automation.import_manual(plan, ticket, content, filename, expected_sha256)` が指定SHAと確認票を照合し、候補だけを登録する。手動画像制作画面でもSHAを表示し、この共通処理で照合する。採用は自動化しない。

バックグラウンド処理はアプリのプロセス終了で中断され得る。常駐ジョブサーバーや自動再送は追加しない。エラー時は保存先・空き容量・既存復旧画面を確認して再承認する。プロンプトZIPはページ描画実績として記録しない。GitHub作品同期のmanifestや同期対象は変更しない。

## Macの確認

```bash
git fetch origin
git switch feature/phase5b-automation
python3.11 -m venv work/mac-5b-venv
source work/mac-5b-venv/bin/activate
python -m pip install -r requirements-dev.txt
brew install ffmpeg
python -m pytest -q
python scripts/verify_production.py --output work/mac-5b-demo
MANGA_DATA_DIR="$PWD/work/mac-5b-demo/data/projects" python -m streamlit run app.py
```

ホームで対象と順序を確認し、承認前にボタンが無効であること、実行後にページPNGが保存されること、動画編集・権利確認で停止することを確認する。動画画面で3形式計画を確認・保存してから自動進行を再開する。アプリを再起動し、同じ処理で既存ファイルを再利用することを確認する。Python 3.12は別venvで同じpytestを実行する。Mac実機・本物の生成画像と日本語音声・権利は人間の確認が必要。

改善候補は、常駐ワーカーによるキャンセルと細かな進捗、書籍内部の差分合成、アップロードZIPの専用画面、脚本変更の影響範囲をさらに限定する人物/画像の再確認、無料の日本語音声エンジン。予算上限500円/全作品月間5,000円と有料画像送信無効は維持する。
