# 自動漫画制作MVP

確認日：2026-10-28（日本時間）。動画は今回の必須工程から外します。

**現状：無料モックではテーマ入力から8ページ24コマ・PNG/PDF/PNG ZIPまで接続済み。Geminiテキストは接続実装済み・今回の実通信未検証。実画像APIは比較・ユーザー承認・最大課金契約の確定待ちで無効です。実AI画像による完成漫画ができたという意味ではありません。**

## 棚卸しと優先順位

| 再利用する既存実装 | 利用する処理 | 今回の差分 |
|---|---|---|
| StoryAIService / AIStoryStore / StoryStore / EditorialStore | 企画、脚本候補、構造検証、採用保存、脚本確定、応答・請求復旧 | 新規作品の指定範囲で企画→先頭案→初稿を引き継ぐ。実APIの評価・改善を追加送信しない |
| CharacterAIService / CharacterProposals / ArtworkStore | 抽出、Gemini設定案、根拠区分、部分採用、UUID、基準画像 | 一括承認した新規人物だけ制作登録。既存人物との照合候補・不明話者では停止 |
| CharacterAIStore | バイブル・参照画像・設定履歴 | 制作採用した設定を既存バイブルへ保存。外見・権利確認を済ませたとは扱わない |
| ImageAIService / ImageAIStore | 基準/コマ候補、SHA・版・人物検証、人間のレビューと別操作の正式採用、採用復旧 | 同一画面で基準画像とコマ画像をまとめて確認。実送信は禁止のまま |
| direction_drafts | 正式脚本の根拠からの作画指示、競合検知・既存指示を上書きしない保存 | 未保存コマを依存順に処理。任意の構図等は推測で確定せず空欄を維持 |
| PageStore / default_page / Automation / StudioStore | セリフ分離、吹き出し配置、差分PNG、PDF、ZIP、ハッシュ付き出力履歴 | ページ構成を画像計画より先に固定。既存Automation.executeの漫画出力だけを使用 |
| BudgetedExecutor / BudgetLedger | 作品累計500円、全作品月間5,000円、実行権、未確定請求停止 | Gemini最大3送信の範囲を事前表示・承認し、各既存Serviceの見積・単発送信境界を通す |

優先順は①画像APIの比較と送信停止の維持、②新規作品の保存可能なオーケストレーター、③画像確認の集約、④PNG/PDFの実出力、⑤失敗・競合・予算・画面テストです。画像APIの新しい送信処理を未承認のまま追加しません。

## 使い方と承認範囲

「ホーム → テーマから新しい漫画を制作」、またはプロジェクト管理の「テーマから新しい漫画をまとめて制作」から始めます。テーマ・ジャンル・ページ数・画風を入力し、方式を選びます。入力中や画面表示ではAPIを呼びません。

開始前に、新規作品UUID・保存先、企画3案の先頭を使う方針、制作脚本の保存・確定、一意な新規人物の制作登録、無料処理の順序、送信対象と最大額を明示します。**この一括制作の明示承認は新規作品内の制作採用の許可です。作品の品質・人物一致・素材権利・公開可否の承認ではありません。** 既存画面の個別採用・修正・履歴・公開品質の確認は利用できます。

Geminiは企画・初稿・人物設定の最大3回。既存の1送信の実行権と共通台帳は各回で維持します。評価・改善は範囲外で、無断連続実行しません。無料から有料への切替、モデル変更、リトライ、GitHub同期、SNS投稿も行いません。無料枠でも有料相当最大額を予約する既存ルールです。

外部送信するのは入力条件、新規作品内で生成された企画・脚本・人物抽出・設定テキストです。既存作品を取り込まず、画像・音声・APIキーを本文・ログ・作品JSONへ含めません。キーは既存の安全な環境変数から、既存アダプターが認証ヘッダーにだけ使用します。

無料モックの場合も、基準画像を一覧で確認→確認記録→別操作で正式採用・再開→コマ画像を一覧で確認→確認記録→別操作で採用・出力、と進みます。26枚を1枚ずつ別画面で操作する必要はありません。モックのレビューはtest-onlyとして残り、実際の外見一致・権利・完成品質を保証しません。

## 画像APIの公式比較

以下はStandard/通常同期、正方形1K相当、再生成なしの**画像出力部分だけ**です。24枚はコマ画像のみ、26枚は人物2名の基準画像を1枚ずつ追加した例です。最大請求額、実測品質、無料利用の保証ではありません。

| 候補・設定 | 1枚 USD | 24枚 USD | 26枚 USD | API無料枠 |
|---|---:|---:|---:|---|
| Gemini 3.1 Flash Lite Image / 1K | 0.0336 | 0.8064 | 0.8736 | なし |
| Gemini 3.1 Flash Image / 1K（公式丸め値） | 0.067 | 1.608 | 1.742 | なし。AI Studioの試用と別 |
| GPT Image 2 / Low 1024x1024 | 0.006 | 0.144 | 0.156 | Free tier非対応 |
| GPT Image 2 / Medium 1024x1024 | 0.053 | 1.272 | 1.378 | Free tier非対応 |
| FLUX.2 [klein] 4B API | 未確認 | 未確認 | 未確認 | 未確認 |

- **Gemini Liteを最初の接続候補とします。** 既存Google接続を再利用しやすく、参照画像編集・人物の一貫性を公式が説明しています。1K限定、入力65,536/出力4,096トークン、thinking minimal/high、検索非対応。入力は$0.25/百万、テキスト・思考出力は$1.50/百万、画像出力は$30/百万です。上記画像価格だけで最大料金を決めません。日本漫画・カラーの24コマ実品質は未検証です。[モデル仕様](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite-image)・[公式料金](https://ai.google.dev/gemini-api/docs/pricing)。
- **Gemini Flash Image**は参照画像を使った編集の候補です。今回調べた1K出力額はLiteより高く、入力・思考・検索等は別料金。日本漫画での優劣は実測していません。[画像生成ガイド](https://ai.google.dev/gemini-api/docs/image-generation)。
- **GPT Image 2**はLowなら出力部分が安く、参照画像の高忠実度入力に対応します。テキストと画像入力も課金され、人物の連続生成が必ず一致するわけではありません。LowとMedium/Highの漫画品質を同一と扱いません。組織確認が必要な場合があります。現行ガイドは2.5 Sunburst/Flareも案内していますが、今回の表は正式に取得できた2の料金を使い、自動で最新モデルへ切替しません。[料金と制約](https://developers.openai.com/api/docs/guides/image-generation)・[モデル/利用Tier](https://developers.openai.com/api/docs/models/gpt-image-2)。
- **FLUX.2 Klein 4B**は複数参照・ローカル重み（Apache 2.0）の候補です。公式API料金表の金額を取得できなかったため推測せず未確認とします。ローカルでも約13GB VRAMのGPU条件が示されており、Intel Mac/macOS 12で無料・快適に動くとは判断しません。[公式料金](https://docs.bfl.ai/quick_start/pricing)・[仕様/ライセンス](https://docs.bfl.ai/flux_2/flux2_overview)。

Googleは生成物の所有権を主張しませんが、利用者に法令・権利・規約への責任があります。無料枠にはデータ利用条件もあり、ChatGPT/Geminiアプリの無料画像枠をAPI無料枠とは扱いません。[Google規約](https://ai.google.dev/gemini-api/terms)。OpenAIは規約の範囲で出力の権利を利用者へ帰属させますが、入力の権利と利用結果の責任は利用者にあります。[OpenAI規約](https://openai.com/policies/services-agreement/)。BFLのローカル4B重みのライセンスとHosted APIの契約は別です。

**想定費用例**：Liteの26枚の出力部分は$0.8736。仮の150円/USDなら131.04円、仮に税1.10を掛けると144.144円。安全係数1.25なら180.18円ですが、入力・思考・テキスト生成を含む最大額ではありません。Gemini 3.5の既存料金JSONで1送信の最大予約例が73.328640円なら、テキスト3回は最大219.985920円です。単純合計400.165920円は**入力・思考等を取りこぼした例**なので、500円以内の保証・実行許可には使用しません。実際の為替・税・上限は本人の保存済み設定で計算します。

機械可読な調査記録は`docs/manga-mvp-image-providers.json`。比較専用で、全候補`maximum_charge_verified=false`、`network_enabled=false`です。実行用の料金JSONと混用しません。既存Gemini画像アダプターの停止フラグ・根拠確認を解除しません。

## 保存・停止・復旧

- 制作元は既存ProjectStore、脚本はStory/AIStoryStore、人物と画像はArtwork/ImageAIStore、配置はPageStore。重複する正本は作りません。StudioStoreの`manga_mvp`は承認範囲と処理履歴のみです。
- 同じ入力nonceの開始は同じ新規UUIDを返し、二重クリックを別作品・別課金にしません。既存作品のUUIDへ一括制作を後付けしません。
- 既存Automationと同じ作品ロックを使い、実行単位は最大128。長い処理はバックグラウンドへ分離し、画面は3秒ごとに状態を更新します。停止要求は現在の単位が終わってから反映されます。
- 次工程は保存済みStoreから再判定します。完了した企画・候補・人物・画像・ページ出力を再利用し、表示フラグだけで完了にしません。
- 途中保存失敗は、既存の応答保存・課金復旧・採用ジャーナルを使います。応答不明・欠損・不正の場合は新しいAPI依頼を作らず停止。予約はGoogle側の確定情報を人間が照合するまで保持します。
- 元の共有台帳が欠損/変更された場合は送信しません。素材の手動変更は再検査を要求します。脚本の別版への変更は自動で引き継がず既存編集機能で確認します。
- PNG/PDF/ZIP出力は既存Automationの差分判定・既存rendererを使用します。音声・動画は生成しません。

## 最後に行うMacの1作品テスト

細かなPhaseごとの実機テストは要求しません。まずコードレビュー・オフラインテストを完了させ、画像APIのモデル・最大料金契約と有料送信の承認後に、以下の**1回のE2E**を行います。

1. 既存作品・共通予算台帳をバックアップし、従来の永続保存先を維持。仮想環境で`python -m pip install -r requirements-dev.txt`、`python -m streamlit run app.py`で起動。
2. テーマ「桜色のタイムカプセル」、青春、8ページ、白黒漫画を入力。新規保存先、全APIの最大額と残予算、外部送信範囲を確認し「漫画を制作」。
3. 企画・脚本・人物の保存、基準画像→コマ画像の順序、一覧確認と別操作の採用を同じ制作ホームで行う。現在のPRでは実画像API境界で停止するので、これを実AI漫画のE2E成功とは扱わない。
4. 実画像APIを承認して接続した後、同じ新規作品でPNG8枚・PDF・ZIPを取得し、ページ順、24コマ、人物、セリフ、権利、テスト画像混入を最後にまとめて確認する。
5. 実行途中で一度アプリを閉じ、同じ作品を開いて再開。履歴・ID・予算台帳が残り、完了済み工程と送信が増えないことを同じE2E内で確認する。

無料モックで工程の流れを先に見たい場合も同じ操作です。結果はTEST IMAGE入りで、公開品質の確認には使えません。実通信・Intel Mac上の実性能は今回未検証です。
