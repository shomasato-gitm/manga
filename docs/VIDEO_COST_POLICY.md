# 音声・動画制作の費用方針

既存の共有BudgetedExecutorと永続SQLiteを唯一の有料送信境界とします。
**作品生成開始からの累計500円・全作品月間5,000円**の両方を守り、作品枠を月替わりに戻しません。
並行ワーカーは同じDBと初期化記録を使います。作品に過去の有料ジョブがある場合、異なるDBパスで再開しません。

- Pollyの料金は公式URL・確認日・engine・文字単価・為替上限・税・安全係数を手動確認します。固定の未確認単価を自動適用しません。
- 1発話は読み3000文字以下、SSML全体4000 UTF-8バイト以下。課金文字数より多いSSML全バイト数を最大利用量として予約します。
- PriceQuote / usage_limitsには再試行0回を指定します。HTTPリダイレクトとアダプターの再試行も禁止します。
- 生成前の一括見積に加えて各送信時も予約します。残額不足・未知の費目・料金期限切れ・請求不明・未確認の超過・台帳不整合では停止します。
- 応答の請求対象文字数が不明なら0円精算しません。タイムアウト後に自動再送したり予約を解放したりしません。
- 成功音声と請求記録を対応付け、保存途中なら同じジョブで保存だけ再開します。明細照合や課金済み音声を使わない決定も履歴へ残します。
- キャッシュ再利用とモックは予算予約もAPI送信も0回。明示的な再生成だけは新規課金対象です。

精算額は応答利用量×確認済み単価×設定為替×税の**予算上の円換算額**です。AWSの最終請求書・実決済額を取得したものではありません。
為替・税の安全側設定を利用者が確認し、未知の追加費用や個別最低料金があれば承認しないでください。
例の160円/USD・税1.10・安全係数1.25は説明用の仮定で、市場為替や個人の請求条件の保証ではありません。
無料枠・AWSクレジットは予算計算で当てにしません。AWS他サービス費用やChatGPT契約料はこの音声単価へ含めません。

料金例・商用条件・公式出典は [TTS比較](tts-provider-comparison.md)、共通台帳の復旧操作は [予算管理](video-budget-phase1.md) を参照してください。
開発とCIではモックだけを実行し、有料TTSは別の明示承認・専用環境・上限付き少量試験まで有効にしません。
