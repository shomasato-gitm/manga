# 今後の処理の追加先

この段階にはサービスの実装はありません。将来、以下の責務ごとにPythonモジュールを追加します。

- ストーリー生成・評価とネーム生成
- キャラクター設定・画像生成・品質評価
- セリフ配置・Pillowによるページ構成・PNG/PDF出力

画面は `app.py`、データは `models.py`、JSONの読み書きは `storage.py` に分けます。
APIの呼び出しを画面へ直接書かず、ここに追加する関数から行うと、APIを使わないテストも書きやすくなります。

将来の再開機能では、成果物を保存してから `workflow.artifacts` と `completed_steps` を更新します。
費用上限は `budget.limit_usd`、累積費用は `budget.spent_usd` に10進数の文字列で記録する想定です。
上限確認・利用額予約・失敗時の精算・二重実行対策はAPI導入時に実装が必要です。
現在は項目の保存と再読み込みだけを行い、処理再開や費用上限の強制はまだ行いません。
