# AI制作アシスタントの返答例

ChatGPTの返答を模したキャラクター・24コマ作画・参考作品・評価・改善のJSONです。実際のAI評価や確認済みの作品分析ではありません。

このフォルダは固定のデモ用プロジェクトID・ストーリー版ID・依頼IDを使った形式例です。そのまま任意のプロジェクトには取り込めません。
**実際に取り込みを試すときは、アプリで依頼を作成し「返答形式を確認」→「動作確認用の返答サンプルJSON」をダウンロードしてください。**
現在の依頼ID・ストーリー版・人物IDに合わせたサンプルになり、ChatGPTもAPIも使わずに取り込み→編集→選択採用まで試せます。
デモの設定を実作品に採用する場合は、内容を確認・修正してください。取り込んだだけでは既存設定は変わりません。
